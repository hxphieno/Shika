# 候选展开按钮交互（2026-09-26）

收起时，右侧固定 72pt 区域现在直接命中可见箭头。箭头是候选滚动视图的兄弟视图，因此候选横滑识别器不会接管从箭头开始的触摸。候选文字和其余空白仍由原有滚动视图处理，空白轻点继续展开。

首次命中边界保持严格；只有已经按在箭头上的触摸才允许向原区域外漂移 8pt。移动时的高亮和松手时的校验使用同一区域。明显拖离后通过取消触摸结束，不会因为 UIButton 自身更大的移动容忍范围而继续展开。展开后的整行收起交互保留。

## 专项验证

```sh
python3 scripts/test-candidate-disclosure.py <booted-simulator-UUID>
python3 scripts/test-candidate-disclosure.py <booted-simulator-UUID> --interactive
python3 scripts/test-keyboard-acceptance.py <booted-simulator-UUID> --candidates-only
```

热区回归通过 **10,231 项**断言，覆盖 320、402、874pt 宽度，1、3、30 个候选，首尾滚动位置，箭头/候选/空白的命中归属，展开后的整行收起，额外头部留白，以及空状态和重试按钮。

交互测试页直接使用生产 CandidateBarView，分别显示长候选列表、单候选列表和下方相邻按键；计数器显示展开、选词和邻键点击次数。底部黄色条是没有自定义热区的标准 UIScrollView，用于识别测试工具自身的滑动限制。

在 iPhone 17 Pro / iOS 26.5 模拟器上通过 CUA 指针操作确认：

- 在箭头内部横向移动后松开，成功展开。
- 从箭头移到左边界外约 6pt、下边界外约 5pt，成功展开，选词/邻键计数不增加。
- 从箭头明显移到候选区内部约 38pt，取消展开，也不选中候选。
- 直接点箭头左侧候选，选词计数增加；直接点箭头下方，邻键计数增加；均不展开。
- 单候选后的空白轻点仍可展开。

这些指针操作验证了按下与松手的归属，不能等同于真机连续手指横滑验收。当前 CUA 拖动对候选区和标准 UIScrollView 对照都没有触发 pan 事件，故不声称完成原生横滑的动态验收；热区测试仍检查候选和空白保留滚动祖先、允许滚动取消点击，箭头独立于滚动祖先。

## 回归范围

候选专项入口通过 **770 项**检查，复用现有整体验收中的两套键盘候选检查，覆盖反复展开/收起、待确认文本、候选自然宽度和不同屏宽。检查结束恢复测试进程原有模式偏好。

整套历史键盘验收此前仍使用旧的 `mode.<scheme>` 标识、60pt 边界和未计入右侧 inset 的滚动宽度判断。本次同步修正这三个与候选回归有关的测试假设。整套验收还存在符号单/双引号输出和旧“点击语言按钮轮换模式”的断言失败；当前模式按钮已使用菜单，这些断言不作为本次候选改动通过的依据。

额外运行真实 UITextView 的待确认文本与展开候选测试，30 项中通过 29 项；唯一失败为旧断言“组合中回车确认后立即插入换行”，当前输入策略是组合中先确认。本次未修改回车或模式菜单的生产行为，也未将这两套历史回归报告为全部通过。未进行实体设备验证。
