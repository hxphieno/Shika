# 键盘方案

当前提供「中日混合」和「小鹤双拼」两个独立键盘。点击底部 🦌 双向切换；上次方案保存在键盘扩展自己的 UserDefaults。数字页不改变方案，返回时恢复原方案。中日语言状态只在当前控制器生命周期内保留。

当前仅实现 UI 和原始按键输入，尚未接入转换引擎：双拼注音是提示，不参与转换，不会自动生成汉字或候选。

## 职责

- `Core`：方案身份、输入事件协议。输入方案与字母/数字页面是两个独立状态。
- `Schemes/ChineseJapanese`：中日键盘、布局和中/日/混合按钮。
- `Schemes/Shuangpin`：独立中文布局、小鹤音节提示及大小写状态，不依赖中日键盘类。
- `UI/Components`：共享按键、气泡、注音键、候选栏等。
- `UI/Layouts`：共享底部功能栏及数字标点页。
- `UI/Theme`：尺寸、间距、颜色。
- `KeyboardViewController`：页面与方案切换、偏好保存、iOS textDocumentProxy 对接。

未来接入引擎时，在输入事件与系统文本接口之间增加转换处理；不要把转换逻辑放进按键组件，也不要让日文状态决定双拼行为。

## 小鹤键位来源

- https://flypy.cc/
- https://github.com/rime/rime-double-pinyin/blob/master/double_pinyin_flypy.schema.yaml

普通单字母声母沿用字母；U/I/V 额外标出 sh/ch/zh。下方标韵母，多韵母分两行显示。ü 使用拼音字符显示（编码中的 v），üe 对应 ue/ve 写法。这是小鹤双拼提示，不含小鹤音形辅码、零声母解析或编码转换。

## 验收

1. 默认中日页，点击 🦌 到小鹤双拼；再次点击返回。
2. 双拼有 26 个字母，无日文长音键、无中日语言切换。
3. 切换前后的中日语言状态保持；重新创建控制器恢复上次输入方案。
4. 双拼进入 123 页，点击返回仍是双拼。
5. q/v 输入字母而非 iu/ui/ü；空格、换行、删除正常。
6. 双拼 Shift 单击为单次大写，双击或长按锁定，再单击回小写。
7. 检查 320、390、430 点宽度下的键位、双行韵母与气泡；真机确认触摸手感和键盘扩展生命周期。
