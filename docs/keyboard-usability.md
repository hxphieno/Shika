# 键盘易用性调整（2026-09-25）

前序待确认文本及单行候选栏独立收尾于 `b251b4e`。以下项目各自提交，保持 Rime 解码、纠错和上屏策略不变。

## 1. 按键预览边界

气泡挂在所属键盘的容器内，并约束在容器的上边界及左右边界之内。根据后续反馈，已撤销首排缩小头部的处理：所有字母的气泡头部保持 51pt 高、37pt 字号；首排顶至根视图顶部 2pt 留白，空间不足仅缩短连接腰部。Q 的左侧与按键对齐、竖直向上，右侧倾斜连接；P 镜像处理。候选栏仍为 44pt，键盘布局和总高度不变。

## 2. 模式标识与候选空间

空候选时，模式控件的左边界与首排 Q 键左边界同为 6.5pt。出现候选时整个模式控件隐藏，UIStackView 回收其占位，候选从同一左边距开始。清空或确认组合后恢复当前模式标识；展开候选时也不保留模式占位。

## 3. 中日模式记忆

中、日、混合模式使用独立的 `shika.chineseJapaneseMode` 偏好值。点击切换时立即保存，新控制器从该值恢复；切到双拼不会覆盖它。首次运行、旧版本未保存或无效值均回退到混合模式。不存储正在输入的组合文本。

## 4. 数字与符号页

左侧数字九宫格、0/返回/删除的位置不变；右侧仍横向滚动，使用四行等宽列。前两列为中文常用标点，之后依次为中文括号引号、日文引号、英文标点、网址邮箱字符、英文括号、运算、单位和货币等，共 60 个不重复选项。开闭括号/引号拆成独立键，点击输出对应单侧字符；省略号 `……` 和破折号 `——` 保留完整写法。没有添加自动配对或自动移动光标等输入规则。

## 5. 操作热区

候选单项至少 44×44pt，较长词按单行文字的自然宽度加两侧内边距分配宽度，防止被压成上下两行；去掉候选之间 4pt 的死间隙；展开/收起按钮使用 72×44pt 的固定热区，直接接收触摸，独立于候选滚动手势。只有已在箭头区域按下的触摸才允许向边界外漂移 8pt；高亮和松手检查使用同一容错范围，明显移开时取消，重试至少 44×44pt。首次触摸不越入候选列表或主键区。候选文字与空白处继续参与原生横滑，空白处轻点仍可展开；候选和符号滚动允许从按钮开始拖动，并取消按钮点击，避免滑动变成误上屏。专项验证见 [候选展开交互](candidate-disclosure-interaction.md)。主字母区已有不重叠的半间隙热区，继续沿用。数字/符号键补齐横向各 3pt、纵向各 6pt 的半间隙热区；数字与符号按所在区域分开，符号不越过滚动视口，整个数字页不越过自身边界。

展开候选仅在当前数量不足首屏容量时预取，重复开合不再追加新页、反复重建候选条；向下浏览时继续按原逻辑加载。后续修正的截图、热区及反复开合验收见 [独立复核](keyboard-preview-followup-acceptance.md)。

## 6. 原生表情入口（2026-09-26）

移除扩展内自绘的表情页和分类数据。中文、日文、中日混合、自然码双拼的底栏统一使用地球按钮：轻点切换到下一个系统输入模式，长按或向上滑动打开系统键盘列表，选择已启用的「表情符号」键盘。iOS 没有公开接口让第三方键盘直接指定切换到 Emoji；这里使用 [Apple 的系统键盘切换接口](https://developer.apple.com/documentation/uikit/uiinputviewcontroller/handleinputmodelist(from:with:))，不承诺轻点必然进入 Emoji。

按钮将完整触摸事件交给 UIKit。交接前提交当前组合文本并停止连续删除；无触摸事件的辅助功能激活使用 `advanceToNextInputMode()`。返回后保留原输入模式。
