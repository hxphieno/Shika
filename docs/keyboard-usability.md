# 键盘易用性调整（2026-09-25）

前序待确认文本及单行候选栏独立收尾于 `b251b4e`。以下项目各自提交，保持 Rime 解码、纠错和上屏策略不变。

## 1. 按键预览边界

气泡挂在所属键盘的容器内，并约束在容器的上边界及左右边界之内。候选栏缩至 44pt 后，首排不再沿用越出扩展边界的 67pt 上伸尺寸，而是根据可用高度缩短气泡帽；后排仍保留正常尺寸。Q/P 的气泡向内收，文字和气泡轮廓一同调整，不能靠关闭本地 `clipsToBounds` 绕过系统对扩展的裁切。

## 2. 模式标识与候选空间

空候选时，模式控件的左边界与首排 Q 键左边界同为 6.5pt。出现候选时整个模式控件隐藏，UIStackView 回收其占位，候选从同一左边距开始。清空或确认组合后恢复当前模式标识；展开候选时也不保留模式占位。
