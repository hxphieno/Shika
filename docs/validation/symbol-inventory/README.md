# 符号键盘原生对照（2026-09-26）

本次按 iPhone 项目语境，将用户提到的“MS 原生”暂按 **iOS 原生键盘**理解；没有进行 Windows / 微软键盘的完整对照。

## 数据与范围

核对本机 Apple iOS 26.5（23F77）模拟器中的默认、英文、简体中文、繁体中文及日文键盘资源。具体文件和每个符号的来源键见 [ios26-symbols.json](ios26-symbols.json)。读取 `Roman-Accent-*` 与 `UI-Currency-*` 的 `Strings`（实际输入值，不使用视觉 `Keycaps`），取全部由 Unicode 标点或符号组成的条目，去重后为 115 项。

这包括长按/变体选项，不代表 115 项在所有语言、地区和布局的首页同时出现；对照范围不包含字母、数字、颜文字和 emoji。运行时不读取苹果私有资源，也不调用私有 API。

原符号库 60 项，新增 56 项，共 116 项；覆盖本次审计的全部 115 项，并保留原有数学减号 `−`。原来的 60 项维持默认顺序，新项追加在后。

## 角标与记忆

易混淆的括号、引号、句读符号在右上角显示“中日”或“英”，说明常见书写习惯，不表示 Unicode 字符只属于某种语言（弯引号也可用于英文）。数学、货币等通用符号不强行归类。角标不参与点击、不加入实际输入；VoiceOver 可读对应说明。

新旧开闭括号、引号按一组参与频率排序，维持开在前、闭在后，不跨四键列或前 16 键边界。仍使用原本的本地计数，不迁移、不清空用户的已有记忆。

## 验证

`Tests/SymbolInventoryChecks.swift` 通过原生资源审计清单核对覆盖；验证每一个键的精确输入、窄屏/普通屏/横屏及浅深色模式的角标布局，并检查新增配对符号和已有使用记录。

验证结果：iOS 26.5 / iPhone 17 Pro 模拟器通过 **4,276 项断言**。键盘按 320×216、402×216、874×162 点分别渲染浅色和深色截图，已人工检查 320 点浅色和 874 点深色的角标与符号间距。测试使用真实键盘视图及事件接收器，不涉及输入法引擎变更；这不是实体设备触摸测试。

复现：`python3 Tests/run-symbol-inventory-checks.py <已启动模拟器的 UUID>`。脚本将源码快照编译到临时测试宿主中，输出结果及截图目录；不会改动其他模拟器。
